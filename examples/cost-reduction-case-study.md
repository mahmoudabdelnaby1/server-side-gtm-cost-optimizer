# Case Study: Riyadh E-Commerce Store Cloud Run Cost Slashed 68%
- **Baseline:** Store processed 14M events/mo, costing $210/mo on GCP Cloud Run.
- **Intervention:** Deployed `filter_noise_events.py` rules and dropped scroll events.
- **Outcome:** Server bill dropped from $210/mo to $64/mo while 100% of purchase CAPI data remained intact.
